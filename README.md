Package Installer (HyperOS Mod)
==============================
A lightweight yet powerful package installer for Android. This is a fork of
[vvb2060/PackageInstaller](https://github.com/vvb2060/PackageInstaller) that adds
**Root** as a first-class privilege backend, a launcher entry with a permission
checklist, an in-app app manager, and a modern (dynamic color) UI.

Why the fork
-----------
- Upstream only works through Shizuku. Devices that are rooted but do not run
  Shizuku could not use it at all.
- Upstream has no launcher activity: every action starts from an installer
  intent. On HyperOS 3 the *app info → install source* entry no longer resolves,
  so there was no way in to the uninstall / disable / clear-data actions.

What's added in this fork
-------------------------
- **Root backend**: privilege is resolved per call. Root (`su`) is preferred;
  Shizuku is used when no root is available. Root installs go through
  `pm install-create / install-write / install-commit` with the APK streamed
  over stdin, so nothing is written to disk and the same flags as the binder
  path are kept (`-i`, `-r`, `-d`, `--skip-verification`,
  `--bypass-low-target-sdk-block`). Uninstall, disable/enable, clear-data,
  install-existing and app-info lookups also have root paths.
- **Launcher + permission checklist**: `MainActivity` reports which privilege is
  in effect and which permission is still missing (root, Shizuku service,
  Shizuku permission, remote `INSTALL_PACKAGES`), each with the button that
  grants or starts it.
- **App manager**: `AppListActivity` lists installed apps (all / user / system,
  searchable) and exposes uninstall, disable/enable, clear data, open and app
  info — this is the replacement entry for the broken HyperOS 3 "install
  source" shortcut.
- **Modern UI**: rounded cards, pill buttons, and dynamic color from the system
  accent (`system_accent1_*`) on Android 12+, with hand-rolled views so the APK
  stays small. All install dialogs share one card shell (`CardDialog`).
- **New application id**: `com.hyperosmod.packageinstaller`, so this build can
  coexist with the upstream app.
- Signed with the HyperOS Mod release key.

Known limitations
-----------------
- Root mode cannot do "add more splits" step by step (a Shizuku session has to
  stay open between dialogs) and cannot remove a single split. Both fall back to
  an error message; use Shizuku mode for those.
- Root mode streams the payload, so install progress shows copying then jumps to
  commit; `pm` gives no byte-level feedback during the commit itself.
- Root installs spawn one `pm` process per split, which costs a few hundred
  milliseconds each.

Build
-----
Requires JDK 25 and Android SDK platform 37.2 / build-tools 37.0.0.

```bash
./gradlew :app:assembleRelease
```

Release signing reads `KEYSTORE_PASSWORD`, `KEY_ALIAS` and `KEY_PASSWORD` from
the environment and expects the keystore at `../keystore.jks` (repository root).
Without them the build falls back to debug signing.

Original features
-----------------
- **Split APKs**: Install `.apks` files generated by `bundletool`, the installer will select the most suitable split APKs.
- **APK Dumps**: Install apps from zipped APK dumps (a zip file containing all base and split APKs from `pm path`).
- **Zipped APKs**: Install a single APK from a ZIP archive.
- **Add Splits**: Add new split APKs to an existing application.
- **Remove Splits**: Remove split APKs from existing application.
- **Interactive Split Installation**: When installing an app that requires splits, user can progressively add more APK files without needing to package them into a single zip file beforehand.
- **Network Install**: Simply send the APK link to the installer to install, no need to download APK file.
- **Instant Preview**: Quickly view package information without slow copying or temporary extraction.
- **Detailed Info**: Displays the version name, API level, split type and signature.
- **Bypass Security Scan**: Skip the Google Play Protect and developer verification during installation.
- **Archive Support**: Restore applications from the network.
- **Private Space Support**: Handles requests to install applications into Android 15 private space.
- **Default Handler**: Auto set itself as the default app for apk file type.
